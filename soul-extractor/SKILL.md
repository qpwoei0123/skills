# soul-extractor

글 샘플에서 문체 지문을 추출하고, 새 글을 그 스타일에 맞게 다듬는 스킬이다.
목표는 사칭이 아니라 허가된 voice profile을 만들고 일관된 글쓰기 초안을 돕는 것이다.

## 불변 규칙

- 허가된 사람, 본인, 브랜드, 창작 캐릭터에만 사용한다.
- 실제 인물이 작성한 것처럼 속이는 용도에는 사용하지 않는다.
- 출력물은 "스타일 참고 초안"으로 취급한다.
- 사실, 경험, 입장, 약속을 꾸며내지 않는다.
- 문체 변환과 내용 창작을 분리한다.
- 문체 일치도는 저자 판별 확률이 아니라 내부 점검 점수다.
- 위험한 대리 발화는 거절하거나 일반 톤 초안으로 낮춘다.

## 금지 사용

아래 요청은 수행하지 않는다.

- 특정 실존 인물이 실제로 쓴 것처럼 보이게 만드는 요청
- 타인을 속이는 이메일, DM, 사과문, 입장문, 계약/협상 문구
- 정치, 금융, 의료, 법률 의사결정에 영향을 주는 대리 발화
- 허가 여부가 불명확한 개인의 사적 말투 재현

안전하지 않으면 문체 분석, 일반 톤 개선, 공개용 초안으로 전환해 제안한다.

## 호출 형태

```text
soul-extractor
soul-extractor "<글을 이 사람 스타일로 다듬어줘>"
소울 익스트랙터
영혼 추출기
```

프로필이 없으면 샘플 수집부터 시작한다.
프로필이 있으면 프로필 선택 후 변환, 작성, 채점을 진행한다.

## 데이터 경로

스킬 폴더는 배포용이므로 런타임 데이터를 쓰지 않는다.

```text
~/.soul-extractor/
└── profiles/
    └── <profile-id>.md
```

프로필 템플릿은 `references/profile-template.md`를 따른다.

## 작동 플로우

```text
[1] 허가 확인 -> [2] 샘플 수집 -> [3] 문체 지문 생성 -> [4] 프로필 완성도 채점 -> [5] 변환/작성 -> [6] 스타일 일치도 리포트
```

## 1. 허가 확인

대상이 실존 인물이거나 애매하면 먼저 확인한다.

```text
이 문체는 본인, 허가받은 사람/브랜드, 또는 창작 캐릭터 기준인가요?
```

답이 불명확하면 개인 사칭 초안을 만들지 말고, 안전한 대안으로 전환한다.

## 2. 샘플 수집

최소 3개, 권장 5~10개의 학습용 글을 요청한다.

- 최근 글과 오래된 글을 구분한다.
- 공개 글, 메모, 기술 글, 짧은 메시지를 섞을 수 있다.
- 글 유형이 다르면 유형별로 표시한다.
- 샘플이 부족하면 바로 쓰지 말고 부족한 이유를 말한다.

샘플을 받으면 아래를 먼저 판단한다.

- 양: 충분한가
- 다양성: 글 유형이 한쪽으로 쏠렸는가
- 최신성: 지금 말투를 반영하는가
- 금지 근거: 안 쓰는 표현까지 잡을 수 있는가

## 3. 문체 지문 생성

샘플을 분석해 `~/.soul-extractor/profiles/<profile-id>.md`에 저장한다.

반드시 포함한다.

- 말투: 반말/존댓말/혼용, 종결어미
- 문장 리듬: 길이, 끊는 방식, 줄바꿈
- 어휘: 자주 쓰는 단어, 접속사, 감탄사, 이모지
- 구조: 도입, 전개, 마무리 습관
- 사고 흐름: 문제를 보는 각도, 의심하는 지점, 결론을 미루는 방식
- 글 유형별 차이: 기술 글, 메모, 회고, SNS 등
- 원문 지문: 샘플에서 짧게 뽑은 대표 표현
- 금지 표현: 샘플상 어색하거나 절대 안 쓸 것 같은 말

## 4. 프로필 완성도

프로필 생성 뒤 점수를 보고한다. 항목과 배점 정의는 `references/profile-template.md`를 따른다.

각 항목은 아래 신호로 채점하고, 신호가 없으면 점수를 임의로 채우지 않는다.

- 샘플 양: 받은 샘플 개수가 권장치(5~10개)에 도달한 정도
- 유형 다양성: 글 유형이 한쪽으로 쏠리지 않고 여러 유형이 섞인 정도
- 문체 지문 선명도: 종결어미/리듬/금지표현이 샘플에서 구체 인용으로 뒷받침되는 정도
- 금지 표현 근거: 안 쓰는 표현을 샘플 근거로 특정할 수 있는 정도
- 최신성: 샘플이 지금 말투를 반영하는 정도

```text
프로필 완성도: 77%
- 샘플 양: 16/20
- 유형 다양성: 14/20
- 문체 지문 선명도: 24/30
- 금지 표현 근거: 8/15
- 최신성: 15/15

보강하면 좋은 샘플:
- 짧은 메신저 말투 2개
- 최근 공개 글 1개
```

점수 기준:

- 90 이상: 바로 변환 가능
- 75~89: 사용 가능, 일부 어색함 가능
- 60~74: 짧은 글만 권장
- 60 미만: 샘플 추가 요청

## 5. 변환과 작성

사용자 요청을 먼저 분류한다.

- 변환: 사용자가 준 글의 사실과 구조를 유지하고 문체만 바꾼다.
- 작성: 사용자가 제공한 사실, 입장, 경험 안에서 새 초안을 만든다.
- 채점: 기존 글이 프로필과 얼마나 맞는지 평가한다.

작성 요청이면 필요한 사실을 먼저 묻는다.

- 실제로 겪은 일
- 반드시 들어갈 주장
- 빼야 할 내용
- 독자와 공개 범위
- 글 유형

사실이 부족하면 상상으로 채우지 말고 빈칸을 질문한다.

## 6. 스타일 일치도

결과물 뒤에 짧은 리포트를 붙인다. 항목과 배점 정의는 `references/profile-template.md`를 따른다.

각 항목은 아래 신호로 채점하고, 신호가 없으면 점수를 임의로 채우지 않는다.

- 어휘: 프로필의 자주 쓰는 단어/접속사/감탄사가 결과물에 실제로 나타나는 정도
- 문장 리듬: 문장 길이와 끊는 방식이 프로필 리듬과 맞는 정도
- 구조: 도입/전개/마무리 습관이 프로필 구조와 맞는 정도
- 사고 흐름: 문제를 보는 각도와 결론 내리는 방식이 프로필과 맞는 정도
- 금지 표현 회피: 프로필의 금지 표현이 결과물에 안 들어간 정도
- 자연스러움: 어색하거나 AI 같은 흔적 없이 읽히는 정도

```text
스타일 일치도: 84%
- 어휘: 17/20
- 문장 리듬: 16/20
- 구조: 18/20
- 사고 흐름: 17/20
- 금지 표현 회피: 8/10
- 자연스러움: 8/10

부족한 점:
- 마무리가 원래 프로필보다 조금 정돈되어 있음
- 접속사가 한 종류로 몰림
```

점수는 자기 점검용이다. "이 사람이 쓴 확률"이라고 말하지 않는다.

## 출력 원칙

- 초안 본문을 먼저 보여준다.
- 그 아래에 스타일 일치도와 부족한 점을 붙인다.
- 위험 경계가 있으면 맨 위에 짧게 알린다.
- 사용자가 원하면 다음 답변에서 프로필 업데이트 후보를 제안한다.

## 중단 조건

아래 상황에서는 작성을 멈춘다.

- 허가 여부가 불명확한 실존 인물의 문체 재현
- 원문 사실을 바꾸거나 없는 경험을 만들어야 하는 요청
- 공식 입장, 사과, 계약, 협상, 정치/금융/의료/법률 대리 발화
- 샘플이 너무 적어 특정인의 문체라고 볼 근거가 없음
- 사용자가 "속이기", "들키지 않게", "진짜 그 사람이 쓴 것처럼"을 요구함

중단할 때는 가능한 안전 대안을 한 줄로 제시한다.
