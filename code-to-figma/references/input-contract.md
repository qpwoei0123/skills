# 작업 계약 4칸

이 스킬은 명령형이 아니라 **작업 계약 4칸을 채워 가는 방식**으로 동작한다.
부족한 칸만 질문하고, 이미 받은 입력값은 보존한다. 확인 순서는 `권한 → 원본 → 목적지 → DS`.

| 칸 | 정의 | 성격 |
|---|---|---|
| Figma 권한 | 로그인/MCP 인증/대상 파일 편집 권한 | 사용자가 지정하는 값이 아니라 스킬이 점검하는 상태 |
| 원본 화면 | Figma로 옮길 화면 — 현재 화면, URL, localhost route, 여러 URL | 지정 없으면 컨텍스트 추론, 그것도 안 되면 질문 |
| Figma 목적지 | 결과를 넣을 곳 — Figma file URL, page, frame/node | 없으면 진행하지 않음 (새 파일 자동 생성 금지) |
| 디자인 시스템 | 재사용할 기존 컴포넌트/변수/스타일 | 지정 없으면 목적지 파일에서 탐색 |

## 1. Figma 권한

- **연결 확인됨**: 확인 사실 + 다음 단계를 한 줄로 알리고 진행한다.
- **연결됐지만 대상 파일 권한 없음**: 해당 파일에서 편집 권한을 받은 뒤 다시 요청하도록
  안내한다. 확인한 대상 URL을 함께 보여준다.
- **로그인/MCP 인증 안 됨**: 인증을 먼저 완료해야 함을 알리고, 인증 후 같은 요청을 다시
  실행하면 이어서 진행한다고 말한다.

권한 문제를 "작업 실패"처럼 말하지 않는다. **막힌 칸이 무엇인지**를 알려준다.

## 2. 원본 화면

- **지정함**: 원본/목적지/방식을 확인 요약으로 보여주고 진행한다.
- **여러 화면 지정**: 픽셀 캡처 후 그리드 정렬 방식으로 전환함을 고지한다
  (편집 가능한 재구성보다 안정적이라는 이유 포함).
- **지정 안 했지만 현재 작업 컨텍스트가 있음**: "현재 작업 중인 화면을 사용하겠습니다"라고
  고지하고 원본을 명시해 보여준다.
- **지정 안 했고 추론도 안 됨**: 원본 페이지 URL / localhost URL / "현재 화면" 중 하나로
  알려달라고 질문한다.

## 3. Figma 목적지

- **URL에 node-id까지 있음**: fileKey + 배치 위치(node 근처)를 확인 요약으로 보여준다.
- **file URL만 있음**: 넣을 위치가 지정되지 않았으므로 새 페이지를 만들어 배치함을 고지한다.
  페이지 이름 예: `Code to Figma - <원본 화면명>`.
- **목적지 없음**: Figma design 링크를 요청한다. 특정 위치에 넣으려면 frame/page를 선택한
  상태의 URL을 보내면 된다고 안내한다. **목적지 없이 진행하지 않는다** — 새 Figma 파일
  생성까지 자동으로 가면 권한/워크스페이스/팀 선택 문제가 커진다.

## 4. 디자인 시스템

`design-system-discovery.md` 참조. 정책 요약:

- 사용자가 DS를 지정하면 **그 DS 우선**
- 지정 없으면 **목적지 파일의 연결 라이브러리/로컬 변수 탐색**
- 탐색 실패 시 **조용히 대충 만들지 않고 품질 저하를 고지**
- 그래도 원하면 DS 미연동 editable layer로 진행
- 배치 픽셀 캡처는 DS 연동 대상이 아님을 명확히 말한다

## 조합별 응답 기준

| Figma 권한 | 원본 | 목적지 | 스킬 응답 |
|---|---|---|---|
| OK | 있음 | 있음 | 실행 전 요약 후 바로 진행 |
| OK | 있음 | 없음 | Figma 링크만 요청 |
| OK | 없음 | 있음 | 원본 화면만 요청 |
| 인증 필요 | 있음 | 있음 | 인증 먼저 안내, 입력값 보존 |
| 권한 없음 | 있음 | 있음 | 해당 파일 편집 권한 요청 |
| OK | 현재 화면 추론 가능 | 있음 | "현재 화면 사용" 고지 후 진행 |
| OK | 여러 화면 | 있음 | 배치 캡처 방식 전환 고지 |
| 모름 | 없음 | 없음 | 한꺼번에 다 묻지 말고 원본 화면부터 질문 |

가장 좋은 톤은 채워진 칸과 빈 칸을 함께 보여주는 것이다:

> Figma로 옮기기 전에 필요한 값 3개 중 2개를 확인했습니다.
> 확인됨: Figma 연결, 원본 화면
> 필요함: 결과를 넣을 Figma design 링크
> 링크를 보내주시면 기존 파일 안에 새 페이지를 만들어 배치하겠습니다.

이렇게 하면 사용자는 "내가 뭘 빠뜨렸는지" 바로 안다.
