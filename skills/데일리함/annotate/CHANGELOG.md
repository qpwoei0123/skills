# Changelog

## 0.2.3

### Changed
- 실행 계약과 후보 판정의 중복 설명을 줄이고 실제 작업 순서 중심으로 경량화
- 코드 정리와 주석을 함께 요청하면 trim 검증 후 최종 diff에 annotate를 적용하도록 연계 순서 명시

## 0.2.2

### Added
- Codex 스킬 목록에 표시할 이름·설명·기본 프롬프트 메타데이터 추가

## 0.2.1

### Removed
- 전역 지침과 중복되는 문체 재진술 정리: "짧고 쉬운 한글", "명확하면 달지 않음", 블록 주석 전환 지침 — 스킬의 차별점(후보 발굴 휴리스틱, 위험도 게이트)만 남김

## 0.2.0

### Added
- `/annotate` 응답 형식에 실제 값이 채워진 본보기 1개 추가
- 형제 스킬(trim/commit) 경계를 구분하는 트리거 음성 케이스 추가

### Changed
- description에 "왜·조건·주의점" 의도와 trim/commit 경계 안내 명시
- `위험도` 값을 낮음/중간/높음 세 가지로 고정하고 `--go` 반영 규칙과 어휘 통일

### Fixed
- '동작 변경 시 보류'·'추측성 설명 금지' 원칙 중복 정리(불변 규칙에 표준 진술 통합)

## 0.1.0

### Added
- `/annotate` 계획 모드와 `--go` 즉시 실행 모드 정의
- 작업 관련 로직에만 짧은 한글 주석을 남기는 판단 기준 추가
- 과잉 주석, 추측성 주석, 동작 변경을 막는 중단 조건 추가
