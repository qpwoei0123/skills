# Changelog

## 2.1.0

### Changed

- 역할에 맞는 공통 판단 모듈을 스킬 본문에 포함하고, 겹치는 개별 지침을 공통 원본으로 통합

## 2.0.0

### Changed

- 목록 설명에서 버전·호출 예시를 빼고 공백 포함 30자 이내의 행동 설명으로 축약

- 데일리 도구를 `⚡`로 구분하는 닷 접두사 적용

- 호출명·목록 표시명을 `good`에서 `.⚡good`으로 변경하고 닷 스킬 브랜드 적용
- 스킬 간 참조·호출 예시·검증 경로를 동기화하고 저장 폴더는 `good` 사용

## 1.0.0

### Added
- trim 0.4.2와 annotate 0.2.3의 코드 정리·맥락 주석 기능을 good으로 통합
- 주석만·코드만·후보만 요청의 범위를 보존하는 단일 실행 흐름 추가

### Changed
- 기본 호출을 실행으로 정하고 자연어 계획 요청과 기존 --go 표기를 함께 처리
- 후보 등급과 고정 보고 양식을 제거하고 동작 변화의 근거와 관련 검증을 기준으로 판단
- 기존 사용자 작업·git index·동시 변경 보호와 공통화 기준 유지
