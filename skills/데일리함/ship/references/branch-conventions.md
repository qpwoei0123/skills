# 제출을 막는 브랜치 규칙 확인

기여 문서에 명시된 규칙이 있거나 현재 이름이 실제 제출 조건과 충돌할 때 읽는다.

- 사용자 지시와 명시된 저장소 규칙을 우선한다.
- 최근 브랜치의 이름은 관례를 이해하는 참고 자료다. 비율이나 표본 수만으로 새 필수 규칙을 만들지 않는다.
- 이름이 익숙한 패턴과 다르다는 이유만으로 rename 선택을 요구하지 않는다.
- 명시 규칙과 충돌해 제출할 수 없으면 이유와 가능한 이름을 제안한다. 사용자 지시 없이 rename하지 않는다.
- Conductor 등 작업 환경이 branch 이름을 관리하면 해당 지시를 따른다.
