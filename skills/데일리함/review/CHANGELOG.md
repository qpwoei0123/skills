# Changelog

## 3.1.0

### Changed

- 역할에 맞는 공통 판단 모듈을 스킬 본문에 포함하고 기존 작업 범위 유지

## 3.0.0

### Changed

- 목록 설명에서 버전·호출 예시를 빼고 공백 포함 30자 이내의 행동 설명으로 축약

- 데일리 도구를 `⚡`로 구분하는 닷 접두사 적용

- `won-context-review`를 `데일리함/review`로 옮기고 호출명·표시명을 `.⚡review`로 변경
- 작은 로컬 diff도 바로 검토하도록 범위를 정리하고 미커밋 변경과 원격 revision의 근거를 구분
- 고정 조사 절차와 중복 판정 규칙을 줄이고, 코드로 확인할 의문·확인된 결함·사람의 결정을 구분
- 필요한 자료가 없는 경우에만 검토 한계를 밝히고, 질문 수·보고 틀·답변 시점 표시를 강제하지 않도록 정리

## 2.0.0

### Changed

- `context-review`의 폴더명·호출명·목록 표시명을 `won-context-review`로 변경
- 호출 예시와 스킬 간 참조를 새 이름으로 동기화하고 기존 실행·데이터 계약은 유지

## 1.0.0

### Changed

- 고정 질문 수·보고 형식·파일 수 통계를 필요한 범위와 결정 질문 중심으로 변경
- 작은 변경은 직접 검토하고 병렬 조사는 독립 범위와 실질적 이점이 있을 때 사용
- 스냅샷·직접 근거·기존 답변 확인·검토 불완전 구분은 유지

## 0.1.0

### Added
- PR/MR과 연결 자료를 행동 단위 변경 지도로 압축하는 읽기 전용 흐름 추가
- base/head snapshot을 고정하고 플랫폼별 diff·discussion 수집 누락을 막는 자료 수집 규칙 추가
- 코드로 답할 수 있는 의문을 먼저 제거하고 인간 판단이 필요한 질문만 남기는 계약 추가
- 근거성·고맥락성·의사결정성·단일성·신규성 5개 질문 관문 추가
- 질문 0개와 자료 접근 실패로 인한 검토 불완전 종료를 구분하는 출력 추가
