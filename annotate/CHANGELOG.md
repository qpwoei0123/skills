# Changelog

## 0.2.0

### Added
- `/annotate` 응답 형식에 실제 값이 채워진 본보기 1개 추가
- 형제 스킬(trim/commit) 경계를 구분하는 트리거 음성 케이스 추가

### Changed
- description에 "왜·조건·주의점" 의도와 trim/commit 경계 안내 명시
- `위험도` 값을 낮음/중간/높음 세 가지로 고정하고 `--go` 반영 규칙과 어휘 통일

### Fixed
- '동작 변경 시 보류'·'추측성 설명 금지' 원칙 중복 정리(불변 규칙에 표준 진술 통합)

## 0.1.0

### Added
- `/annotate` 계획 모드와 `--go` 즉시 실행 모드 정의
- 작업 관련 로직에만 짧은 한글 주석을 남기는 판단 기준 추가
- 과잉 주석, 추측성 주석, 동작 변경을 막는 중단 조건 추가
